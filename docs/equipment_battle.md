# 派遣ギルド！ 装備・戦闘仕様（装備・戦闘系タスク時だけ渡す）

## 職業・スキル
- 戦士：防御・かばう・挑発・鉄壁・捨て身・反撃
- 神官：ヒール・ミドルヒール・状態回復・リザレクト・神の加護
- 盗賊：近道・宝箱発見・罠解除・奇襲
- 魔法使い：火球・雷撃・氷槍・魔力探知・魔力集中

## 探索
- 近道：帰還時間短縮（出発直後表示）
- 宝箱：追加抽選+1
- 罠解除：DEX×3% +盗賊補正25% 最大90%（DEX30以上は70%上限）

## 装備個体管理
- 個体差：plus / enhance / options / optionCandidates / locked
- 保管庫内は storageUid で個体識別
- 旧セーブの storageUid はロード時に補完

## 合成
- STEP1：育成対象1本選ぶ（同一id・保管庫内・非装備中・非artifact・enhance無し・plus20未満）
- STEP2：同じidの素材を選ぶ（保護中・装備中・artifact・enhance有りは不可）
- 必要素材：plus 0〜9は3本、plus 10以上は5本
- 合成成功後も育成対象は維持→連続合成可能

* 合成ロジック自体は保持している。
* ただし、保管庫UIからは一旦外している。
* 現在は `storageFusionUiEnabled = false`。
* 既存の `plus` 装備、表示、ステータス反映は維持している。
* 将来、必要になれば再開する余地あり。
