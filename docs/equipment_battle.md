# 派遣ギルド！ 装備・戦闘仕様（装備・戦闘系タスク時だけ渡す）

## 職業・スキル
- 戦士：防御・かばう・挑発・鉄壁・捨て身・反撃
- 神官：ヒール・ミドルヒール・状態回復・リザレクト・神の加護
- 盗賊：近道・宝箱発見・罠解除・奇襲
- 魔法使い：火球・雷撃・氷槍・魔力探知・魔力集中

## 状態異常
- 呪い：受けるダメージが増える、状態回復で解除可能
- 睡眠：`sleepTurns` で管理。眠っている間は行動不能、ダメージを受けるか状態回復で解除。ボスには付与しない
- `攻↓（atkDownTurns）`：味方専用。敵へ与える最終ダメージが20%低下する。最終ダメージに `0.8` をかけ、小数切り捨て・最低1ダメージを維持する。ターン経過・状態回復で解除。敵側には適用しない
- モスメイジ：低確率で呪い付与
- ベルウィスプ：低確率で呪い付与

## 草原敵
- ゴブリンチーフ：序盤ボス。`strongSlashLite` で50%の確率で「強斬り」を使う
- 強斬り：単体に通常攻撃の約1.3倍ダメージ
- 共通ボス溜め攻撃なし

## 遺跡敵
- 忘鐘の遺跡にラブルバット / アイビースケルトン / ストーンガード / ベルウィスプ / 封室の守護者を追加
- 忘鐘の遺跡3小区画と旧 `ruins` の敵配置は新敵構成へ更新済み
- ラブルバット：遺跡の軽い敵。特殊行動なし
- アイビースケルトン：基礎アンデッド。特殊行動なし
- ストーンガード：50%で通常攻撃の代わりに「石打ち」を使う
- ベルウィスプ：`curseWhisper` で低確率呪い付与
- 封室の守護者：遺跡ボス。`stoneEcho` 内で石響きと封じの咆哮を使い分ける
- 石響き：生存中の味方全員へ小ダメージ
- 封じの咆哮：単体に通常攻撃の約1.1倍ダメージ。未麻痺対象に低確率で麻痺1ターン
- 共通ボス溜め攻撃なし

## 森ボス名
- 森ボスの表示名は `森の番獣` から `フォレストファング` に変更済み
- フォレストファング：`biteCrushLite` 内で `噛み砕き` / `威嚇` に分岐する。特殊行動全体は50%発動、内訳は噛み砕き70% / 威嚇30%
- 噛み砕き：単体に通常攻撃の約1.3倍ダメージ
- 威嚇：ダメージなし。未付与の生存味方1人に `攻↓` を2ターン付与。全員付与済みなら噛み砕きまたは通常攻撃に戻る
- 敵ID / 出現エリア / 戦闘処理 / `special` は変更なし

## 沼敵
- 沈み灯の沼にマッドスライム / マッドフロッグ / リードリザード / 水底の手 / マッドトードを追加
- 沼3小区画と旧 `swamp` の敵配置は新敵構成へ更新済み
- 沼系装備の `dropEnemies` は新敵IDへ更新済み
- マッドフロッグ：軽い跳びかかり攻撃あり
- リードリザード：後衛を狙いやすい
- 水底の手：絡みつきで低確率スロー付与
- マッドトード：沼の幼生を呼ぶボスに整理
- マッドトード：沼しぶき削除、ボス溜め攻撃対象から除外
- 沼の幼生：`A / B / C` 表示

## 探索
- 近道：帰還時間短縮（出発直後表示）
- 宝箱：追加抽選+1
- 罠解除：DEX×3% +盗賊補正25% 最大90%（DEX30以上は70%上限）

## 装備個体管理
- 個体差：plus / enhance / options / optionCandidates / locked
- 保管庫内は storageUid で個体識別
- 旧セーブの storageUid はロード時に補完

## 合成
- STEP1：育成対象1本選ぶ（同一id・保管庫内・非装備中・非artifact・enhance無し・plus20未満）
- STEP2：同じidの素材を選ぶ（保護中・装備中・artifact・enhance有りは不可）
- 必要素材：plus 0〜9は3本、plus 10以上は5本
- 合成成功後も育成対象は維持→連続合成可能

* 合成ロジック自体は保持している。
* ただし、保管庫UIからは一旦外している。
* 現在は `storageFusionUiEnabled = false`。
* 既存の `plus` 装備、表示、ステータス反映は維持している。
* 将来、必要になれば再開する余地あり。

## 装備研究
- 装備入手時に研究進捗が増加
- 装備図録に研究進捗を表示
- 研究進捗は売却価格を少し上げる
- 研究進捗は分解成果に影響しない
- 追加抽出率は廃止

## 分解
- 分解では確定OPのLvぶんのかけらを得る
- 「研究が進むまで分解しない方が得」にならない設計
- 保管庫に装備を貯め込ませない方針
