# 派遣ギルド！詳細設計書

## コンセプト

プレイヤーはギルドマスター。
「戦うゲーム」ではなく、派遣し、帰還を待ち、報告書を読むゲーム。

世界観： - 暗い - 静か - 少し不穏 - 羊皮紙 - 真鍮 - 暗木 - Wizardry /
古いTRPG風

禁止： - ネオン - サイバー - 大げさな絶叫演出

## 絶対ルール

-   未来情報表示禁止
-   派遣開始時に最終結果表示禁止
-   ログ進行とHP表示を同期
-   死亡者は会話禁止
-   死亡者は行動禁止
-   冒険開始直後の赤表示禁止

ログ方針：

悪い： 「うおおお！」
