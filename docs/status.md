- 月影の森3派遣先に `recommendedLevel` / `description` を追加済み
- 旧 `swamp` / `ruins` / `canyon` / `glacier` は互換用に保持し、派遣先一覧からは除外

- `volcano` の解放条件は氷原最終小区画へ接続
- 派遣先詳細モーダルを追加済み
- 詳細モーダルは派遣先名 / 推奨Lv / 派遣時間 / 出現敵 / ボス / 説明文を表示
- 詳細モーダルは月影の森側でも推奨Lv / 説明文を確認可能
- 詳細ボタンは現在選択中の派遣先を参照
- 詳細モーダルは背景クリックと［閉じる］で閉じられる
- 未解放派遣先の `（○○を1回クリア）` 表示を削除
- 未解放派遣先はグレー表示・選択不可、解放後は通常表示で選択可能
- 状態異常：呪いを追加。受けるダメージが増え、状態回復で解除可能
- `攻↓ / atkDownTurns` を追加。味方専用の一時デバフで、敵へ与える最終ダメージが20%低下する。最終ダメージに `0.8` をかけ、小数切り捨て・最低1ダメージを維持する。ターン経過・状態回復で解除され、敵側には適用しない
- 敵特殊行動：モスメイジが低確率で呪いを付与
- 草原敵：アックスゴブリン、ゴブリンアーチャー、メイジゴブリンを追加
- 草原敵：アックスゴブリンに低確率の強攻撃を追加
- `goblinChief` に `strongSlashLite` を追加
- ゴブリンチーフは50%で通常攻撃の代わりに「強斬り」を使う
- 草原敵：ゴブリンアーチャーは後衛を狙いやすい
- 草原敵：メイジゴブリンは低確率で火球を使用
- 忘鐘の遺跡に新敵5体を追加（ラブルバット / アイビースケルトン / ストーンガード / ベルウィスプ / 封室の獣）

- ラブルバット / アイビースケルトン / 封室の獣は現時点で特殊行動なし

## SET装備
- SET装備実装済み（装備名に `(S)` 表示、真鍮テーマ）
- 旅人一式：冒険時間 -10%、LUC +10
- 同一キャラ3点装備で発動。小隊内分散では発動しない
- 同名効果は小隊内で1回のみ有効
- 帽子・外套・靴の3種類が必要（同名2点ではNG）

## 冒険時間
- `area.durationMs` 基準
- 派遣先表示と実際の `endsAt` は同じ計算
- 短縮効果は共通計算へ接続済み。同名短縮効果は重複不可
