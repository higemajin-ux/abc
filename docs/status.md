# 派遣ギルド！ 現在の実装状況（バグ修正・実装時に渡す）

## 現在の主要実装

- キャラ詳細は「ステータス / 装備 / スキル」タブ化済み
- 小隊メンバー名タップで詳細開閉
- 同じキャラを再タップすると詳細を閉じる
- キャラ詳細側の［閉じる］ボタンあり
- 派遣先細分化：始まりの草原3分割（平原入口 / 平原道中 / ゴブリンの巣）実装済み
- 派遣先細分化：月影の森3分割（遠吠えの道 / 苔むす獣道 / 巨獣の縄張り）実装済み
- 状態異常：呪いを追加。被回復量低下、状態回復で解除可能
- 敵特殊行動：モスメイジが低確率で呪いを付与
- 草原敵：アックスゴブリン、ゴブリンアーチャー、メイジゴブリンを追加
- 草原敵：アックスゴブリンに低確率の強攻撃を追加
- 草原敵：ゴブリンアーチャーは後衛を狙いやすい
- 草原敵：メイジゴブリンは低確率で火球を使用
- 敵図録：`traitsText` による特徴文表示に対応済み

## SET装備
- SET装備実装済み（装備名に `(S)` 表示、真鍮テーマ）
- 旅人一式：冒険時間 -10%、LUC +10
- 同一キャラ3点装備で発動。小隊内分散では発動しない
- 同名効果は小隊内で1回のみ有効
- 帽子・外套・靴の3種類が必要（同名2点ではNG）

## 冒険時間
- `area.durationMs` 基準
- 派遣先表示と実際の `endsAt` は同じ計算
- 短縮効果は共通計算へ接続済み。同名短縮効果は重複不可

## 納品通知
- 右下表示・最大4件・縦積み
- 出現0.30秒／表示7秒／消滅0.60秒
- 複数小隊帰還時も通知を上書きしない

## 小隊カード更新
- 変化があった小隊だけ更新する方針
- select/dropdownが進行バー更新で閉じないように注意

## ステータス表示
